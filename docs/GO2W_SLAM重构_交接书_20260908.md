## 6. 运维与安全红线

1. **机器狗每次重启 → 先重启映射栈**，检查 `imu_status.mode`（见 §2）。
2. **`pkill -f` 有自杀风险**（会匹配到自己的 shell）：用明确 PID 或 `timeout` 让进程自己退出。
3. **不要 `git add .` / `git reset` / `git clean`**：控制主机 181 个未提交改动、机器狗 76 个。
4. **真实运动只做"小幅自闭合"**（前进/后退/小角度旋转），**每次必须回到胶带原点**。
5. **`--operator-authorized-rotation` 会绕过"pose-bound rotation lease"**，只在受控测试里用。
6. WebUI 搜索默认 `control_enabled=false`（只读）；dry-run 会话不发运动。
7. **报告 NOT VERIFIED，不要放宽阈值**。阈值改动必须写明理由并留痕。
8. `surface_thickness_p95` 用**固定半径 0.20 m** 邻域（不是固定 k）——固定 k 会让稀疏地图虚高。
9. `scan_overlap_metrics` 会先读 `frame_id`：**`aligned_scan` 已经在 `pslam_odom` 系**，
   不能再变换、也不能再做位姿补偿（重复补偿实测把 B 从 0.0433 放大到 0.0680）。
