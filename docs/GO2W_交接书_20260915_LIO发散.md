## 3. 今天的核心结论（三次发散）

### 3.1 唯一两次都命中的判据

坏帧 = `iter >= 10` 且 `fix_t == 0.0`，取**连续段长度**，阈值 **10 帧**（10 Hz，即 1 秒）：

| 数据 | 最长连续段 |
|---|---|
| 13:20 健康段 12000 帧 | 8 |
| 实验常速段 7837 帧（含急转，已自恢复） | 8 |
| 12:40 静止段 + 急转窗 3041 帧 | ≤8 |
| **12:40 发散** | **24** |
| **13:20 发散** | **33** |

**双向注入校准**：负样本合计 **22,878 帧零误报**；
12:40 首次报警在 `v=1.33 act=0.924`（**提前 29.5 秒**），13:20 在 `v=2.54 act=0.866`（**提前 0.4 秒**）。

**单帧出现是转弯瞬态，连续才是发散。**

### 3.2 ⚠ `ab` 判据只在 12:40 成立，13:20 完全失效

- **12:40**：死亡前 534 秒 `ab` 从 0.052 爬到 0.486 单调不回落（其余指标全正常），可提前 10 分钟报。
- **13:20**：**`ab` 全程 0.111 稳在正常带，直到死透才飙到 114。没有任何爬升。**
- 教训：**"`ab` 单调爬"不是判据**——正常预热也是减速渐近爬，同一族曲线，只是渐近值不同。
- **基于 n=1 建的判据，用到 n=2 上第一次就失效。**

### 3.3 转弯力度不是触发因素（已证伪，别再查）

|---|---|---|
| 健康段 10999 帧 | **1.186** | 23 |

**10 秒后真正弄死它的那个转弯 `|Δw|=0.936`，比好几个没杀死它的转弯都温和。**

### 3.4b 时钟阶跃这条假设，已经证明是可测的（新）

停机时从 `/tmp/go2w_bag/exp1`（12:52:08 → 13:07:33）里挖出 **229,978 条 `/utlidar/imu` 原始消息**，
用「接收时刻 − header 时刻」做两机时钟差，结果：

| 量 | 值 |

| 时钟差（接收 − header） | 823.576 → 823.599 s，**15.4 分钟里只漂 22.7 ms** |
