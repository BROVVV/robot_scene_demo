## 1. 为什么重启

| 项 | 值 |
|---|---|
| 内核模块 `NVRM version` | **580.173.02** |
| 用户态 `libnvidia-ml.so.1` | **580.178.04** |
| `nvidia-smi` | `Failed to initialize NVML: Driver/library version mismatch` |
| `torch.cuda.is_available()` | **False** |

典型"更新了 nvidia 包但没重启"。后果：`grounded_sam_worker` 静默 fallback 到 CPU，
RAM++ swin_large 单次语义请求 **137 秒**（历史 GPU 上是秒级），
`--max-seconds 180` 只够 1 次推理 → 永远搜不到目标，且超时后卡在推理里不退
（SIGTERM 要等推理返回，实测拖了 4 分半）。

**重启后第一件事**（确认修复成功）：
```bash
nvidia-smi --query-gpu=name,driver_version --format=csv        # 应正常输出
/home/mxt/anaconda3/envs/go2_robot_scene_demo/bin/python -c \
  "import torch; print('cuda:', torch.cuda.is_available())"    # 应为 True
```
若仍为 False，**不要继续 B4**，见 memory `go2w-gpu-driver-library-mismatch`。
